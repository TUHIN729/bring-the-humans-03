## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `VIDEO.json` — the video's full TikTok address — to `/output/VIDEO.json`. The video file itself is `video.mp4` in this repository.
